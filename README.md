# Веб-приложение для автоматизации работы кафе-кондитерской

Курсовой проект, БГУИР, 2025.

Многопользовательское веб-приложение для кафе-кондитерской: клиенты просматривают каталог, собирают корзину и оформляют заказы, администраторы управляют ассортиментом и заказами.

## Возможности

- Регистрация и авторизация с валидацией (JWT)
- Каталог продукции по категориям с детальной информацией
- Корзина и оформление заказов
- Админ-панель: управление ассортиментом и заказами
- Разграничение доступа по ролям (клиент / администратор)

## Стек

**Backend:** Java 17, Spring Boot 3, Spring Security, Hibernate (JPA), PostgreSQL 15, JWT
**Frontend:** React 18

## Запуск

### Требования
Java 17, Maven (или `./mvnw`), Node.js, PostgreSQL.

### База данных
Создать базу `cafe_db` в PostgreSQL.

### Backend
```bash
export DB_USERNAME=ваш_логин
export DB_PASSWORD=ваш_пароль
export JWT_SECRET=любая_строка_не_короче_32_символов
cd cafe-project/backend/cafe-app
./mvnw spring-boot:run
```
Сервер запустится на http://localhost:8080.

### Frontend
```bash
cd cafe-project/cafe-frontend
npm install
npm start
```
Приложение откроется на http://localhost:3000.

## Тестовый администратор

При первом запуске создаётся учётная запись администратора (см. `DataInitializer.java`). Для реального использования пароль необходимо сменить.
